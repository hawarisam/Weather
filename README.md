# Northline Weather

A simple static weather app for Detroit using the Open-Meteo API.

## Run locally

Open `index.html` in a browser, or serve the folder with any static server.

## Publish on GitHub Pages

Push this folder to a GitHub repository, then enable **Settings > Pages** and choose the branch containing `index.html` as the deployment source.

The app uses the public Open-Meteo forecast endpoint and does not need a private API key.
